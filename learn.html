How a link finds a file

  1. The sleigh starts in the folder of the file the link is written in (the gold box), not at the top of the site.
  2. Each / is one step.
  3. foldername/ means "go into that folder."
  4. ../ means "go up one folder."
  5. The last part is the file name. It has to match exactly, capital letters included: Tree.png is not tree.png on GitHub Pages.
